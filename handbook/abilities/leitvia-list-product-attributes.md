# leitvia/list-product-attributes

Generated from Leitvia Studio 1.3.45. Do not edit. Group: Read. How to call abilities, hashes, autonomy and rejections: [agent handbook](../README.md).

**List product attributes.** Lists the global product attributes with their values and hash. Per attribute ID, name, slug (taxonomy pa_\*) and sort order, per value ID, name and slug, in the order the shop shows them. Attributes a single product defines for itself are part of leitvia/get-product.

MCP tool `leitvia-list-product-attributes`, REST GET. Annotations: readonly true, destructive false, idempotent true. Only registered while woocommerce is active.

No input.

Output: `attributes` array of object.
