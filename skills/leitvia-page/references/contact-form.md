# Contact form

Details for `leitvia-page`. Read this when visitors should write from a page.

A page that takes messages uses the pattern `leitvia-studio/cta-contact-form` in the `actions` slot of the frame `contact`, or at the close of a service page. It holds the block `leitvia/contact-form` (name, email, message, sent with `wp_mail()`), so no plugin is needed. `leitvia/cta-contact` only lists ways to reach the person, `leitvia/cta-contact-buttons` closes a page with one button to call (`tel:`) and one to write (`mailto:`); send each with `text` and `url`, the phone number in the button text, and remove the button you have no target for. Never write a form as HTML; `leitvia/wizard` only sends URL parameters.

- After the page exists, set the attributes of the block with `leitvia/update-block`: `recipient` (never printed on the page, empty: the administration email of the site), `subject`, `nameLabel`, `emailLabel`, `messageLabel`, `requiredNote`, `buttonText`, `successMessage`. Empty texts are the translated defaults in the language of the site, so set them only for wording of your own. Ask the person which address gets the messages.
- Keep `privacyNote` true: it links the privacy policy page, and the link shows only while that page is set and published. `leitvia/audit-site` reports the check `privacy-page` when it is not. Publish the page, then `leitvia/set-privacy-page` with its ID; like every setting it waits for a person in a change package. The privacy policy must name the form.
- Send one test message before the site goes live, or ask the person to: a site without working mail shows the visitor an error.
- Other fields, uploads, several steps or stored entries need a form plugin, which only a person installs; wrap it in `leitvia/form-errors`. For inquiries with photos and applications Gravity Forms is the supported plugin: [Gravity Forms](gravity-forms.md).
- Appointments: Fluent Booking (free on WordPress.org, installed by a person) is the supported booking plugin. The theme gives its calendar the tokens of the site (card, buttons, days, fields, focus, light and dark, also on an inverse band) and loads that style only on pages with a calendar; the colors and the light or dark theme chosen in the plugin do not apply. Put the shortcode or block of the plugin in a section of its own: `wrap` of `leitvia/insert-section` with a `heading` ([block edits](block-edits.md)). The plugin prints the event title as an h1 in the browser, which no check of Studio sees; the theme sets it to the size of a card title. Name the second h1 in your report and ask the person to keep the event title short, in the language of the site.
